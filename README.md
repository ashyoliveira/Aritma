# Aritma

Calculadora interativa desenvolvida para praticar fundamentos de JavaScript
e operações matemáticas.

## 📌 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📌 Conceitos

- Funções
- `prompt()`
- `Number()`
- Condicionais
- Operações matemáticas
- Manipulação do DOM
- `querySelector()`
- `innerText`
- `console.log()`

## 📌 Funcionamento

O usuário escolhe uma operação matemática e informa os valores necessários
para que o resultado seja calculado e exibido na página.
